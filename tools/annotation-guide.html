annotating a score

Caplin sets out how an analysis is written onto a score: what goes above the staff, what goes below, and which marks carry which meaning. Caplin's own Example 2.1 is here, reduced to quarters and halves so the annotation stands clear of the surface, and annotated by those rules. Turn a layer off to see what the score looks like without it, and press a rule to find its mark.

Press any rule on the left to light the marks it governs. The switches turn the annotation layers on and off and move the labels between Caplin's system and the one this course uses, which in a minor key changes almost every chord.
