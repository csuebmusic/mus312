# assets

The stylesheet, scripts, and fonts for the course site.

`style.css` is the stylesheet for all pages.

`theme.js` sets the light or dark ground before the first paint. The palette for each ground is in `style.css`.

`notation.js` draws notation as inline SVG. It's used by every page in `tools/` and `review/`.

`workbook.js` draws the blank staves and the print control on the pages in `review/`.

`fonts/` holds the self-hosted fonts and their licenses.

Notation set in Bravura, Steinberg Media Technologies. Text set in IBM Plex. Both under the SIL Open Font License.
